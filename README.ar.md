## شلون تستخدمها؟

١. افتح صفحة الأداة واقرأ شنو تدخل وشنو يطلع لك.
٢. انسخ مثال JSON إلى صفحة الإدخال في Apify.
٣. راجع السعر الحالي، شغّل، ونزّل النتائج JSON أو CSV.

للتشغيل البرمجي، اتبع إعداد Python في الصفحة الإنجليزية. الحساب والمفتاح خاصّين فيك؛ لا تنشر المفتاح. الأمثلة مدفوعة حسب تسعير الأداة، والسكربت يرسل حد رسوم افتراضي $0.10 لكل تشغيل.

هذه أمثلة استخدام لكود العميل؛ كود الأدوات الخاص غير منشور هنا. اختبارات التشغيل صغيرة ولا تضمن شمول كل موقع أو استمرار توفر البيانات. المراقبة الدورية تحتاج إعداد جدول منفصل.
